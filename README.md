# Паллета — семейное меню на неделю (пилот v0.5)

Публичный браузерный сервис: **7 дней × завтрак, обед, ужин = 21 блюдо**, единая корзина, фасовки, смена SKU и замена рецепта при подтверждённом дефиците. **Это не подтверждённый заказ и не подключение к 1С в реальном времени.**

## Что работает

- 42 редакционных блюда: 12 завтраков, 14 обедов, 16 ужинов, с черновыми порциями на человека, временем и краткими шагами приготовления.
- Фильтры (время, рыба, молочное, глютенсодержащие ингредиенты, яйца) и предварительный ориентир бюджета.
- Привязка ингредиент → разрешённые SKU. Автовыбор подходящего подтверждённого SKU, расчёт фасовок с учётом **совокупной потребности за неделю**.
- При известном дефиците допускается объединять несколько совместимых SKU по одному ингредиенту. Если ингредиента не хватит даже после доступных замен, генератор выбирает другое блюдо. Если подходящего блюда нет, показывает пустой слот, а не ложное наличие.
- Пользователь может выбрать альтернативное блюдо или совместимый SKU. При изменении корзина пересчитывается.
- Цены/остатки устаревают по установленным срокам: `price_freshness_hours=24`, `stock_freshness_minutes=60`; непроверенные не обозначаются как актуальные. **Полный итог** показывается только при 100% свежих ценах и покрытии корзины подтверждёнными остатками.

## Источник рецептов

Сверена публичная страница [PROРЕЦЕПТЫ](https://berbena.pro/prorecepty): там указаны 120 рецептов, план **на день** и замена блюд. Полная платная база не была доступна для экспорта, поэтому 42 блюда **написаны для Паллеты заново**, а не выдаются за копию PROРЕЦЕПТЫ. Количества продуктов и шаги являются редакционными набросками, требуют кулинарной проверки. Важные домашние ингредиенты (соль, вода, специи) не включены в стоимость. Фильтры не являются гарантией отсутствия аллергенов: проверяйте этикетку и состав.

## «Живой каталог»: корректный источник и ограничения

GitHub Pages — **статический сайт** и не читает 1С напрямую. Сейчас `products.json` содержит 21 SKU/группу товаров, на большинство нет свежего фактического остатка; в части фасованных товаров отсутствуют **подтверждённые коды**. До получения проверенных кодов 1С и регулярной выгрузки эти позиции остаются с пометкой «уточняется». Публиковать внутренние данные 1С и контакты покупателей в GitHub **запрещено**.

### Схема проверенной CSV из 1С

Только публичные поля, разделитель `;`, UTF-8 с BOM либо UTF-8:

```csv
sku_code;retail_price;stock_quantity;captured_at;unit;stock_unit
УТ-00003202;54,90;80;2026-10-09T18:00:00+03:00;кг;кг
```

Это **пример формата, не настоящая цена/остаток**. CSV создаётся в кассовой базе 1С с ценами, применимыми покупателю, и **доступным к продаже**, а не условным учётным остатком. Для `pricing_mode="by_pack"` цена и `stock_quantity` указаны соответственно **за одну упаковку** и **в целых упаковках** (`stock_unit=pack`); для `pricing_mode="by_weight"` цена за кг/л, остаток в соответствующей единице. Поле `captured_at` обязательно со смещением часового пояса. `sku_code` должен соответствовать `Номенклатура.Код для поиска`.

### Проверка импорта и загрузка

```bash
python sync_1c_export.py --csv approved_public_prices_stock.csv --dry-run
python sync_1c_export.py --csv approved_public_prices_stock.csv
# после проверки можно запустить git add/commit/push вручную
```

Опциональный `--push` работает только на компьютере с настроенным локальным репозиторием и GitHub-авторизацией. **В текущем окружении никакого задания экспорта из 1С нет и не настроено.** Для регулярных обновлений понадобится настроить локальный защищённый планировщик выгрузки и разрешённую отправку обезличенного публичного среза на GitHub. На данном этапе интеграция со стороны 1С остаётся **BLOCKED** до реальной рабочей выгрузки.

Не переписывайте историческую среднюю как `current_retail`; не включайте закупочные цены, себестоимость, GP, поставщиков и персональные данные.

## Контроль

Запуск тестов `node test_core.cjs`; проверка открытия сайта в браузере после сборки. Перед продажей: проверить текущие цены/наличие, корректность кулинарных рецептов, аллергенов, актуальный WhatsApp и условия доставки. Полная сумма до подтверждения магазином считается предварительной.

## Автоматическое обновление из 1С

Один пошаговый документ: [`1C_SYNC_SETUP.md`](./1C_SYNC_SETUP.md). Для Windows подготовлен [`run_1c_sync.ps1`](./run_1c_sync.ps1), импортёр проверяет полноту сопоставленных кодов и срок давности (`--require-all-codes --max-age-minutes 20`). Сам источник CSV в 1С и Планировщик заданий нужно настроить на разрешённом ПК; **автоматический экспорт из базы пока не запущен**.
