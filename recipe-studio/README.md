# Мастерская рецептов v0.1 — тестовая ветка

**Статус:** черновик, без выпуска на production и без подключения к Mottor.

## Что работает
- Общая рабочая библиотека из 44 существующих редакционных рецептов Паллеты (../recipes.json).
- Режимы «Паллета» и «berbena»: магазинные цены/остатки отображаются только в режиме Паллеты; в режиме berbena — общий перечень ингредиентов.
- Поиск по названию и ингредиенту, фильтрация по приёму пищи, избранное (localStorage).
- Пошаговый режим приготовления с пересчётом продуктов на число членов семьи; переключатель «на два дня» удваивает ингредиенты, но **не гарантирует безопасность хранения**.
- План на 3/7 дней на основе core.js, замена блюда и повтор на завтра через фиксированный слот.
- Учёт «уже есть дома» исключает позиции из корзины Паллеты.
- Никогда не считаем исторические клубные цены живыми: итог показывается только при confirmedTotal!==null.
- Исключённое мясо никогда не появляется в заказе магазина.

## Что ещё не готово
- Это не новый каталог 120 платных рецептов berbena.pro, импорт Mottor не производился.
- 12 дополнительных собственных черновиков не опубликованы и до кулинарного теста не добавляются в production.
- Нет регистрации, облачной синхронизации, реальной интеграции с 1С, платёжной системы, импорта чужих рецептов из приложений.
- Мобильная браузерная/доступностная проверка и QA порций нужны до слияния.
- Избранное и отметки запасов хранятся только в браузере устройства.
- Повтор на завтра означает повтор блюда в меню, а не подтверждение безопасного хранения готового блюда.

## Локальный запуск
Из корня репозитория:

python -m http.server 8765

Открыть http://localhost:8765/recipe-studio/?brand=palleta или ?brand=berbena.
