# Recipe Studio v0.2: два отдельных сценария

**Статус:** тестовая ветка и draft PR. Основная ветка, опубликованный GitHub Pages и Mottor не изменяются до отдельного решения владельца.

## berbena.pro: рецепты + калории + процесс готовки

URL локально: /recipe-studio/?brand=berbena

- Каталог из 44 **существующих редакционных** рецептов, поиск и избранное.
- Каждый рецепт: время, список ингредиентов, ориентировочные ккал на 1 порцию и пошаговое приготовление.
- Увеличение числа порций и режим на два дня пересчитывают количество ингредиентов и оценку полной калорийности.
- **[Unverified] Ккал пока не подтверждены.** Используются редакционные типовые значения по ингредиентам, НЕ точные USDA FDC записи и НЕ данные упаковок магазина. Расчёт округляется до 10 ккал, не является пищевой этикеткой или медицинской рекомендацией.
- Неподходящая единица измерения или неизвестный ингредиент: расчёт ккал блокируется, не заменяется на 0.
- Метод per 100 g USDA: https://fdc.nal.usda.gov/Foundation_Foods_Documentation/ ; значения из nutrition.js в дальнейшем сверить с пищевой базой, граммовками и технологическими картами.
- Нет страницы меню на неделю, заказа в магазин и клубных цен.
- Полный закрытый каталог PROРЕЦЕПТЫ из Mottor **ещё не подключён**: тест использует только общую редакционную базу и не меняет доступы.

## Паллета: меню и корзина

URL локально: /recipe-studio/?brand=palleta

- Выбор меню на 3 или 7 дней, число людей, замена блюд, повтор на следующий день.
- Уже есть дома, магазинный перечень покупок, продукты вне ассортимента (мясо) отдельно.
- Показ клубной суммы **только** при подтверждённых свежих ценах и наличии. Исторический ценник не используется как текущий.
- Нет каталога, списка избранных, калорийности или пошагового режима готовки.
- Основное приложение Паллеты сохраняет существующий рабочий функционал, данная ветка содержит опытный интерфейс.

## Ограничения

- Данные ккал приблизительны, требуют сверки перед коммерческой публикацией; оценка по сырым/сухим ингредиентам и не учитывает всех особенностей приготовления.
- 12 новых отдельных черновиков не добавлялись в recipes.json до кулинарной проверки.
- Нет личных аккаунтов, облачной синхронизации, нового подключения 1С и автоматических заказов.
- Избранное и домашние запасы сохраняются локально в браузере.
- Готовка «на два дня» не означает, что готовую еду можно безопасно хранить два дня. Требуются отдельные рекомендации для конкретного блюда.

## Запуск и тесты

Из корня репозитория выполнить: python -m http.server 8765
Открыть http://localhost:8765/recipe-studio/?brand=berbena или http://localhost:8765/recipe-studio/?brand=palleta

Проверки: node test_core.cjs, node test_ui.cjs, node recipe-studio/test_studio.cjs,
node recipe-studio/e2e.cjs (для E2E требуются Chrome и Playwright Core).

**Не сливать draft PR в main и не публиковать в Mottor до QA и разрешения владельца.**
